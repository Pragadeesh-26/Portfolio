## Features

- Animated hero section with a typewriter effect cycling through roles
- Sections for About, Skills, Projects, Education, and Contact
- Scroll-triggered fade-in animations using the Intersection Observer API
- Active navigation link highlighting while scrolling
- Fully responsive layout for desktop, tablet, and mobile
- Custom dark theme with neon accents, built with CSS variables

## Deployment

This site is hosted with **GitHub Pages**:

1. Go to **Settings → Pages**
2. Set the source to **Deploy from a branch**
3. Select the **main** branch and the **/ (root)** folder
4. Save, and the site goes live within a couple of minutes
